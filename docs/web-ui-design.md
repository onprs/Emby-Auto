# Web 界面设计规范

本文规定 Emby Auto Web 应用的信息架构、模块内导航、选择控件和动效规则。新增或调整界面时，以本文和现有组件实现为准。

## 信息架构

- 一级导航只包含模块：仪表盘、搜索添加、RSS 订阅、任务、媒体库、操作日志、系统设置。
- 一级导航在桌面端使用左侧边栏，在移动端使用抽屉。侧边栏不展示模块内分区，也不使用可展开的二级菜单。
- 模块内存在两个及以上并列分区时，分区导航放在全局顶栏下方的二级导航条中，以单行页签形式显示和选择。
- 详情页从属于所属模块，不新增一级导航项，也不改变分区导航的单行结构。所属模块的二级导航在列表页和详情页保持可见。

当前使用二级导航的模块：

| 模块 | 分区 |
| --- | --- |
| 任务 | 视频任务、获取记录、下载 |
| 系统设置 | 外部服务、Agent、存储与工具、字幕组、转码 |

分区顺序固定，不随状态、权限或数据量变化。分区切换使用普通页面导航，URL 可直接访问和分享。切换分区时默认不携带列表筛选和分页参数；需要保留来源返回上下文的模块可以只保留 `from` 参数。

## 顶部二级导航

桌面端：

```text
全局顶栏：实时状态                              用户信息
─────────────────────────────────────────────────────
⚙ 模块名  │  分区 A   分区 B   分区 C   分区 D
─────────────────────────────────────────────────────
页面标题
页面说明
```

移动端：

```text
全局顶栏：菜单  实时状态                    用户信息
分区 A   分区 B   分区 C   分区 D
←────────── 单行横向滚动 ──────────→
─────────────────────────────────────
页面标题
```

规范：

- 导航条吸顶，位于全局顶栏正下方，滚动时保持可见。
- 导航条高度 48px，桌面端左侧显示模块名和图标，模块名占用固定宽度，分区区域始终从固定位置开始；移动端隐藏模块名，只保留分区。
- 分区标签使用相同字重，选中状态只改变颜色和滑动指示器，避免切换时文字宽度变化导致布局左右抖动。
- 分区始终单行排列，不换行、不折叠为下拉菜单。空间不足时横向滚动。
- 当前分区自动滚入可视区域；键盘焦点和屏幕阅读器仍可访问全部项目。
- 分区使用页面链接，不使用 ARIA tab 组件。当前项设置 `aria-current="page"`。
- 导航条始终在页面内容之上、全局顶栏之下，不遮挡页面标题。
- 配置加载中或加载失败时，分区导航保持可用。
- 不把二级导航放回侧边栏，也不新增侧边栏展开状态。

## 选择动画

同一选择组内的当前项指示器使用连续滑动效果：

- 指示器沿选择组移动，位置和宽度同时过渡，不出现先消失再出现或逐项跳变。
- 动画时长 260–300ms，缓动使用 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 首次渲染直接定位到当前项，不播放从起点滑入的动画。
- 容器尺寸、字体或标签宽度变化后重新测量，保持与当前项对齐。
- 用户启用减少动态效果时，指示器立即定位，不播放滑动动画。
- 横向选择组保持单行；内容超出时横向滚动，避免指示器跨行产生对角线移动。侧边栏按纵向列表处理，高亮块上下滑动。
- 当前项的文字颜色随指示器到位而过渡；不使用瞬时背景切换。

选择指示器分为三种形态：

| 形态 | 用途 | 示例 |
| --- | --- | --- |
| 下划线 | 模块分区导航、页签式筛选 | 系统设置分区、任务分区、下载阶段 |
| 纵向高亮 | 一级侧边栏导航 | 主导航当前模块 |
| 胶囊 | 状态、阶段等筛选标签 | 视频任务状态、获取记录阶段 |
| 分段底块 | 互斥模式切换 | 映射模式、逐文件处置 |

排序按钮、复选框、开关和行内命令按钮属于状态或命令控件，不属于同一选择组内的滑动选择，不使用滑动指示器。

## 设置页画布

- 系统设置各分区的内容放在同一块白色画布上，不再使用多张独立卡片拼贴。
- 画布使用统一边框、圆角和阴影；内部按分区标题和分隔线组织。
- 每个分区使用二级标题、说明和可选状态徽标，字段在分区内使用响应式网格排列。
- 分区顺序固定，不因服务是否配置、Agent 是否启用而变化。
- 页面级保存操作保留在画布外，作为当前分区的统一动作。

## 品牌资产

- `apps/web/public/brand/icon.svg`：应用图标和浏览器 favicon。
- `apps/web/public/brand/wordmark.svg`：展开侧边栏和移动端抽屉左上角标题。
- `apps/web/public/brand/mark.svg`：折叠侧边栏中的纯标记。
- 标题资产按深色侧边栏设计，图形与文字使用翠绿色和浅色以保持对比。

## 视觉规范

- 主色使用现有翠绿色（`emerald-600`），当前分区文字使用 `emerald-700`。
- 导航条背景为半透明白色并带背景模糊，底边使用 `zinc-200` 分隔线。
- 侧边栏当前项使用浅色高亮块和左侧绿色竖线，高亮块整体滑动；不在单个菜单项上切换背景。
- 当前项下划线高 2px，两端圆角，长度为当前项宽度的内侧部分。
- 胶囊指示器使用 `emerald-100` 背景和 `emerald-200` 描边；当前标签使用 `emerald-950` 文字，未选标签使用透明背景、`zinc-300` 边框和 `zinc-600` 文字，避免遮挡滑动中的指示器。
- 分段控件轨道使用 `zinc-100` 背景和 `zinc-300` 边框，当前项底块为白色并带轻阴影。
- 不给选择组新增装饰性图标或额外说明文字。
- 页面内容继续使用统一最大宽度和左右留白，与导航条对齐。

## 交互规范

- 鼠标悬停使用浅灰背景或加深文字，不能改变选择结果。
- 键盘焦点使用 2px 翠绿色焦点环，与选中状态区分。
- 触控目标高度不小于 44px。
- 分区切换不弹出确认框；页面内未保存内容按各页面现有保存规则处理。
- 移动端切换分区后回到页面顶部，由当前页面或路由行为决定。
- 不支持通过左右滑动手势切换分区，避免与浏览器返回手势冲突。

## 可访问性

- 分区导航使用 `navigation` 角色并提供明确的 `aria-label`。
- 筛选标签组使用 `group` 角色和 `aria-label`。
- 当前分区使用 `aria-current="page"`，筛选和模式使用 `aria-pressed`。
- 所有选择项使用真实链接或按钮，不使用只监听点击的普通容器。
- 横向滚动的选择组不隐藏可聚焦元素，Tab 键可依次访问。
- 当前项自动滚入视野时不触发页面纵向跳动。
- 尊重 `prefers-reduced-motion`。

## 实现约定

- 顶部二级导航统一使用 `SectionTabs` 和 `SectionTabsLayout`。
- 设置页内容统一使用 `SettingsCanvas` 和 `SettingsSection`。
- 侧边栏当前项高亮使用独立测量和滑动指示器，不通过切换每个菜单项的背景实现。
- 横向选择指示器统一使用 `SlidingSelection`，通过 `variant` 选择下划线、胶囊或分段形态。
- 侧边栏纵向高亮由 `NavigationList` 使用相同的测量和动画规则实现。
- 筛选标签统一使用 `FilterChip` 和 `FilterChipGroup`。
- 选择项必须标记 `data-sliding-item`，当前项标记 `data-sliding-active="true"`。
- 选择组切换时通过 `activeKey` 触发当前项定位和自动滚动。
- 新增模块若出现两个以上并列分区，必须使用顶部二级导航；不得恢复侧边栏子菜单。
- 不复制测量和动画逻辑到页面组件，避免同一交互出现不同实现。

## 验收清单

- 侧边栏只显示模块，不显示任何模块内分区。
- 当前模块的所有分区在顶部导航中单行显示，移动端可横向滚动。
- 每个分区可直接通过 URL 打开，当前分区状态正确。
- 切换分区时指示器连续滑动，首次进入不播放滑入动画。
- 筛选标签和分段控件使用相同滑动规则。
- 加载、错误和详情状态下导航仍可见且可操作。
- 键盘、触屏和减少动态效果模式下均可正常使用。
